| Component | Description | Technical Description |
| --- | --- | --- |
| [`ShActionCard`](/guidelines/components/sh-action-card) | Lets visitors submit their email to sign up for a newsletter or subscription. | Props: `urlImage`/`altImage`, `title`, `subtitle`, `text`, `icon`/`altIcon`, `imageBackground`, `urlButton`, `labelButton`, `colorButton` (default `black`), `styleButton` (default `solid`; outline/soft/solid/link/ghost). `ui` exposes `wrapper`, `image`, `title`, `subtitle`, `text`, `button`, `icon`, styled by default as a Tailwind grid in `ShActionCard.ts`. |
| [`ShAlert`](/guidelines/components/sh-alert) | Displays a message of a given severity (info, success, warning, danger) to highlight important information. | Single prop `typeAlert` (default `info`; info/success/warning/danger) selects a background/text/border color set and a Heroicon from `config.alert[typeAlert]` / `config.icon[typeAlert]` in `ShAlert.ts`. `ui` exposes `wrapper`, `base`, `icon` for overrides; slot content is the message body. |
| [`ShAvatar`](/guidelines/components/sh-avatar) | Shows a project member's avatar with their name, role, and links to their social profiles. | Props `srcAvatar`/`altAvatar`, `name`, `role`, `company`, and social URLs `linkedin`/`facebook`/`instagram`/`twitter` rendered as icon links. Default layout is a 2-column CSS grid (`ShAvatar.ts`) with a grayscale, rounded-full avatar. `ui` exposes `wrapper`, `base`, `avatar`, `socials`, `icon`, `name`, `role`, `company`. |
| [`ShBadge`](/guidelines/components/sh-badge) | Displays a short piece of text to represent a status or category. | No content props; slot text is the badge label. Color comes from a `status.ts` lookup table (`a`/`b`/`c`/`d`/`default`) referenced by `ShBadge.ts`'s `wrapper` default. Only style hook is `ui.wrapper`. |
| [`ShButton`](/guidelines/components/sh-button) | Renders a styled link/button that navigates to a given URL. | Props `urlButton`, `target`, `colorButton`, `styleButton` (solid/outline/link/soft/ghost), `rounded`, `disabled`, `fullWidth`, `size` (`2xs`–`5xl`). `ui` exposes `wrapper`/`rounded`. Slot content accepts Markdown and can nest other components (e.g. `ShMultiColumn`). |
| [`ShCard`](/guidelines/components/sh-card) | Shows an image on one side and Markdown-supported text with labels on the other. | Props `urlImage`, `imageBackground`, `title`, `subtitle`, `text`, `leftLabel`/`centerLabel`/`rightLabel`. `ui` splits the layout into `coverImage`/`coverIcon`/`coverText`, `upperBase`/`upperBaseText`, `image`, `lowerBase`, `title`, `subtitle`, `text`, and the three label slots. |
| [`ShCarousel`](/guidelines/components/sh-carousel) | Rotates through a set of slides with navigation controls and optional auto-sliding. | Props `slides` (default `1`, slides shown at once), `timer` (default `2`s, `0` disables autoplay), `direction` (`horizontal`/`vertical`), `navigationVisible` (default `true`). `ui` has shared keys (`wrapper`, `inner`, `track`, `group`, `title`, `subtitle`, `item`, `navigation`) plus a per-`direction` style block; nested components (e.g. `ShMicroCard`) are grouped per visible slide. |
| [`ShColumn`](/guidelines/components/sh-column) | Represents a single column with a header, footer, and body content, for use inside multi-column layouts. | Props `title`, `subtitle`, `footerText`; fixed `size: 1` consumed by parent grids (`ShMultiColumn`/`ShTwoColumns`). `ui` exposes `header.wrapper`/`header.title`/`header.subtitle`, `footer`, and `main` (the latter only editable by changing `sh-column.vue`, not via `ui`). |
| [`ShDynamicTable`](/guidelines/components/sh-dynamic-table) | Renders a data table that fetches, filters, sorts, and queries data from a remote source. | Props `dataUrl` + `dataField` (fetches remote JSON), `columns` (array of `{name, title, filter, query, sortable, type}`), `perPage` (default `10`; `10/25/50/100/-1`), `transformRawData` (hook to reshape fetched data), `autofocusSearch` (default `false`; scrolls to and focuses the search box, skipped when the URL has an anchor or below the `lg` breakpoint). `ui` covers `wrapper`, `base`, `header`, `footer`, `pagination`, `search`, `filter`, `table`, `thead`. |
| [`ShFaq`](/guidelines/components/sh-faq) | Renders a list of frequently asked questions with their answers. | Prop `qas` (array of `{q, a}` pairs, both Markdown-capable) rendered as an accordion; `title` defaults to `FAQs`. `ui` exposes `wrapper`, `inner`, `question`, `q`, `answer`, `a`, `divider`, `icon` per accordion part. |
| [`ShImgContainer`](/guidelines/components/sh-img-container) | Displays an image with an optional caption, mainly used for SVGs that need a unified look. | Props `urlImage`, `altImage`, `figcaption`. `ui` exposes `wrapper`, `inner`, `base`, `image`. Colors invert in dark mode by default, so it works best with black/white artwork. |
| [`ShListCards`](/guidelines/components/sh-list-cards) | Displays a grid of ShCard components, ordered by card ID and filterable by tag. | Props `title`, `subtitle`, `text`, `cols` (default computed via `gridClass`, which auto-picks 1–3 columns under 1300px and lets the author set a value above that), `cardID` (ordered array of card IDs to pull in), `allTags` (enables tag-based filtering). Renders a CSS grid of `ShCard`s; `ui` exposes `wrapper`, `header`, `title`, `subtitle`, `text`, `base`, `gap`. |
| [`ShMicroCard`](/guidelines/components/sh-micro-card) | Shows a small amount of information in a compact card. | Prop `layout` (default `default`; `default`/`flat`/`teaser`/`snap`/`translate`/`opacity`/`cta`/`logo`) selects which namespaced style block (`config[layout].*`) is applied. Links come from either `urlWrapper` (whole card) or `urlButton`/linked `title`/`subtitle`/`text` (never both), with `target` (default `_self`). `ui` covers `wrapper`, `coverImage`, `coverText`, `coverIconWrapper`, `coverIcon`, `image`, `icon`, `title`, `subtitle`, `text` per layout. |
| [`ShMultiColumn`](/guidelines/components/sh-multi-column) | Organizes content into multiple columns and rows. | Props `cols` (grid column count), `gap` (default `gap-4`, a Tailwind gap utility), `class`. Acts as a CSS grid wrapper for nested `ShColumn`/`ShTwoColumns` children; must not be nested inside another `ShMultiColumn`. |
| [`ShSegment`](/guidelines/components/sh-segment) | Wraps a block of Markdown or HTML content in a styleable container; the most flexible layout component. | Props `imageBackground`, `imageBackgroundClass`; primary style hook is `ui.wrapper`. Has no other structural props — it just renders arbitrary nested content inside one styleable `div`, which is why other components (e.g. `ShCarousel`, `ShMicroCard`) are often nested inside it. |
| [`ShSocial`](/guidelines/components/sh-social) | Embeds a social media post (e.g. X/Twitter). | Prop `src` (platform-specific post ID or URL), `width` (default `500`, used for Facebook/LinkedIn iframe embeds), `height`. Renders a provider-specific embed/iframe chosen based on `src`; `ui.wrapper` styles the container. |
| [`ShTextImg`](/guidelines/components/sh-text-img) | Places text and an image side by side, with configurable text span, alignment, and position. | Props `urlImage`/`altImage`, `title`, `subtitle`, `text`, `positionText` (default `right`), `spanText` (default `m`, text column width relative to the image), `alignText` (default `center`), `status` (`a`/`b`/`c`/`d`/`default`, sets background via `config.status`). `ui` exposes `wrapper`, `image`, `title`, `subtitle`, `text`. |
| [`ShTwoColumns`](/guidelines/components/sh-two-columns) | Splits content into two columns in a single row. | Props `size` (default `L`, sets left-column width) and `gap` (default `gap-4`). Wraps exactly two children — first becomes the left column, second the right — in a CSS grid/flex row; `ui.wrapper` styles the container. |
| [`ShVideo`](/guidelines/components/sh-video) | Embeds a video from YouTube or a local source. | Prop `src` (YouTube URL or local video path); renders a responsive embedded player/iframe chosen based on the source type. `ui.wrapper` styles the container. |
